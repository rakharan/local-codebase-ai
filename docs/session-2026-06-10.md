## What's Next

### Phase 1 — AST-Aware Chunking (highest priority)

Current chunker (`src/lib/chunker.ts`) is line/char based — cuts functions in half.  
Rewrite with language-aware split boundaries.

**Rules per language (from plan):**
| Language | Split at |
|---|---|
| TypeScript/JS | function decls, class decls, class methods, exported const objects |
| PHP | `function`/`class` at brace depth 0–1, brace-counting heuristic |
| SQL | each complete statement (`;`), include preceding `--` comment block |
| Go | `func` decls, method decls, struct type defs |
| Markdown | H2 headings; H3 sub-chunk only if H2 > 800 tokens |
| JSON/YAML | single chunk if < 100 lines, else split on top-level keys |
| Config files | single chunk if < 150 lines, else every 100 lines at blank line boundaries |

**Size guardrails:**
- Min: 5 lines or 100 chars — skip smaller (lone braces, single imports)
- Max: 120 lines or ~2000 tokens
- Overlap: 3 lines at boundaries, mark `hasOverlap: true`

**New Qdrant payload fields to add:**
- `chunk_type`: `function` | `class` | `method` | `statement` | `section` | `file` | `block`
- `symbol_name`: function/class/method name
- `parent_symbol`: class name if chunk is a method
- `has_overlap`: true if chunk includes overlap lines

**Acceptance criteria:**
- TS file with 5 exported functions → 5 chunks
- PHP class with 8 methods → 8 method chunks + 1 class-level chunk
- SQL migration with 12 ALTER TABLE → 12 chunks
- No chunk has tokenEstimate > 2000

**Files to touch:**
- `src/lib/chunker.ts` — main rewrite
- `src/lib/files.ts` — may need language detection
- Re-index all repos after (expensive on CPU — do in one pass)
