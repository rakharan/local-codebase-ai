## What We Did Today

### Phase 1 — AST-Aware Chunking ✅

Rewrote `src/lib/chunker.ts` from a line/char sliding window to a language-aware chunker.

**Languages handled:**
| Language | Split strategy |
|---|---|
| TypeScript/JS | function decls, class decls, exported consts via brace-end tracking |
| PHP | class/function/method at brace depth 0–1 |
| SQL | each `;`-terminated statement, include preceding `--` comment block |
| Go | `func` decls, struct type defs |
| Markdown | H2 boundaries; sub-chunk at H3 if H2 section > 3200 chars |
| JSON/YAML | single chunk if ≤ 100 lines, else split on top-level keys |
| Config | single chunk if ≤ 150 lines, else every 100 lines at blank-line boundary |
| Unknown | fixed block split (fallback) |

**New `CodeChunk` fields added:**
- `chunkType`: `"function" | "class" | "method" | "statement" | "section" | "file" | "block"`
- `symbolName?`: function/class/method name
- `parentSymbol?`: class name if chunk is a method
- `hasOverlap`: true if chunk includes 3-line overlap from previous segment

**Schema version bumped:** `branches-v1` → `branches-v2` (forces full re-index)

**Size guardrails:**
- Min: 5 lines / 100 chars (skip smaller)
- Max: 120 lines / 2000 chars
- Overlap: 3 lines at boundaries
