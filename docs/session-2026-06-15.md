### Doctor: HTTP Client Extractor ✅

New extractor `src/doctor/extractors/http-client-extractor.ts` detects outbound HTTP calls:

**PHP patterns:**
- `curl_init("url")` — inline URL
- `curl_setopt($ch, CURLOPT_URL, "url")` — separate setopt
- `NodeAPI::method()` — maps to known ims-tf2 endpoint paths
- `MMBConfig::CONST`, `MrgConfig::CONST`, `TradersConfig::CONST` — resolves config class constants to full endpoint paths

**Node/JS patterns:**
- `axios.get/post(url)`
- `fetch(url)`
- `got.get/post(url)`
- `httpService.get/post(url)` (NestJS)
- Look-back resolution: if URL is a bare variable, scans 5 lines back for `const url = ...` or ternary assignment

**Results on ims-tf:** 195 HTTP calls detected (was 0), including:
- 19 NodeAPI→ims-tf2 bridge calls (jwt-server, login, login-with-mt4)
- All MMBConfig, MrgConfig, TradersConfig endpoint usages
