# TypeScript Style

- Use TypeScript strict style.
- Prefer pure functions for extractors.
- Avoid hidden global state.
- Avoid large classes unless state is necessary.
- Use explicit return types for exported functions.
- Keep filesystem access separate from parsing logic.
- Parser functions should accept strings and return structured facts.
- Use Indonesian comments only for non-obvious business or extraction logic.
- Do not add comments that merely restate the code.
